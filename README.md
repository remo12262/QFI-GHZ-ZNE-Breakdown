# QFI-GHZ-ZNE-Breakdown

Noise-induced breakdown analysis of GHZ states using Zero Noise Extrapolation (ZNE) and Quantum Fragility Index (QFI).

---

## Abstract

This repository presents a computational framework for analyzing the noise-induced breakdown of multipartite GHZ states using Zero Noise Extrapolation (ZNE) and the Quantum Fragility Index (QFI). The project investigates how entanglement degrades under scalable noise models and evaluates the effectiveness of error mitigation strategies in restoring quantum observables. By combining controlled noise amplification with fragility-based metrics, the study provides a quantitative characterization of coherence decay, entanglement collapse, and robustness thresholds. The implementation enables reproducible benchmarking experiments for studying quantum state stability under realistic noisy conditions.
